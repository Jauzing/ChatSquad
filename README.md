# ChatSquad

## Description
ChatSquad is a Streamlit application where you can chat with different AI-based personalities.
The model has some contextual memory and stores all text data as prompt;completion pairs.
This is because the model was originally used to create data for fine-tuning my own model.

## Installation
Install the required dependencies and set your OpenAI API key.

```bash
pip install -r requirements.txt
export OPENAI_KEY="your_api_key_here"
```

## Usage
Run the Streamlit app and start chatting :)

```bash
streamlit run app.py
```
